# UV Python Environment Management Rule
# ====================================

**CRITICAL DEVELOPMENT RULE**: All Python environment management MUST use `uv`

## ✅ REQUIRED: Always Use UV

```bash
# ✅ Correct - Use these commands
uv venv                    # Create virtual environment
uv sync                    # Install dependencies 
uv add package-name        # Add new dependency
uv run pytest             # Run commands in environment
uv run python script.py   # Run Python scripts

# ✅ Development workflow
source .venv/bin/activate  # Activate environment
uv sync --extra all        # Install all dependencies
```

## ❌ FORBIDDEN: Never Use These

```bash
# ❌ NEVER use these commands
pip install package-name   # Use: uv add package-name
pip install -r requirements.txt  # Use: uv sync
python -m pip install     # Use: uv add
virtualenv venv           # Use: uv venv
pipenv install           # Use: uv sync
```

## Why UV is Required

1. **Faster**: 10-100x faster than pip
2. **Reliable**: Consistent dependency resolution
3. **Modern**: Built for Python packaging best practices
4. **Secure**: Better security and validation
5. **Project Standard**: All team members use uv

## Setup Commands

```bash
# First time setup
./scripts/dev-setup.sh

# Daily development
./scripts/dev-commands.sh <command>
```

**Remember**: If you see `pip` or `virtualenv` commands in documentation or scripts, replace them with `uv` equivalents!
